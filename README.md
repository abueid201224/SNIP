# ScrollSnip v2.0.0

أداة لقطات الشاشة المتطورة لنظام ويندوز مع دعم التمرير التلقائي، التكبير عالي الدقة (Per-Monitor DPI v2)، المحرر المدمج، ودعم كامل للغتين العربية والإنجليزية.

---

## ⚡ كيفية الحصول على الملف التنفيذي (.exe) عبر جيت هاب (GitHub Actions)

تم تجهيز مستودع جيت هاب بـ **GitHub Actions Workflow** يقوم تلقائيًا ببناء الملف التنفيذي على سيرفرات ويندوز التابعة لجيت هاب بمجرد رفع الكود (Push):

1. **انتقل إلى مستودع المشروع على GitHub**.
2. اضغط على تبويب **Actions** في الشريط العلوي.
3. ستجد سير عمل باسم **Build Windows Executable (ScrollSnip.exe)**.
4. اضغط على أحدث تشغيل (Workflow Run).
5. في قسم **Artifacts** بالأسفل، ستجد:
   - **`ScrollSnip-Windows-EXE`**: يحتوي على ملف `ScrollSnip.exe` التنفيذي الجاهز للاستخدام مباشرة دون الحاجة لتثبيت بايثون.
6. حمّل الملف وفك الضغط وشغل `ScrollSnip.exe`.

> **ملاحظة:** يمكنك أيضًا تشغيل البناء يدويًا بالضغط على **Actions** -> اختيار **Build Windows Executable** -> الضغط على زر **Run workflow**.

---

## 💻 البناء المحلي على جهاز ويندوز بضغطة زر واحدة

إذا أردت بناء الملف التنفيذي على جهازك الشخصي بنظام ويندوز:
1. انقر نقرًا مزدوجًا على الملف:
   ```cmd
   build_exe.bat
   ```
   أو من خلال PowerShell:
   ```powershell
   .\build_exe.ps1
   ```
2. سيقوم السكربت تلقائيًا بإنشاء البيئة الافتراضية وتثبيت PyInstaller وتجميع `dist\ScrollSnip.exe` وفتح المجلد فور الانتهاء!

## المميزات الأساسية

1. **لقطة بالتمرير (Scrolling Capture)**: خوارزمية كشف الإزاحة التلقائية عبر `cv2.matchTemplate` مع مخزن ذاكرة ذكي محمي بسقف أقصى (`MAX_IMAGE_BYTES = 256MB`) يمنع استنزاف الرام.
2. **لقطة منطقة (Region) وشاشة كاملة (Full Screen)**.
3. **دعم UI Automation و SendInput**: تمرير سلس دون تحريك الفأرة أو معاركة المستخدم.
4. **دقة الشاشات المتعددة (DPI-Aware)**: مطابقة الشاشات المنطقية بالبكسل الفعلي عبر `mss` دون تشويش.
5. **محرر مدمج متكامل**: قلم، قلم تمييز شفاف، مستطيلات، أسهم متجهة، نصوص، تراجع وإعادة، تكبير وتصغير، ونسخ فوري للحافظة.
6. **دعم كامل للغة العربية والإنجليزية**: واجهة RTL/LTR مع قواعد الجموع العربية الصحيحة (مفرد، مثنى، جمع قلة، جمع كثرة).
7. **اختصارات لوحة المفاتيح العالمية**:
   - `Ctrl + Shift + S` : لقطة منطقة
   - `Ctrl + Shift + W` : لقطة بالتمرير
   - `Ctrl + Shift + F` : لقطة شاشة كاملة
